# Meridian — Contact Form

A polished, accessible contact form built with pure HTML, CSS, and JavaScript.

## Features

- Split layout with contact details and a form card
- Fields: name, email, subject (select), and message
- Per-field inline validation on blur/input with accessible `role="alert"` errors
- Live character counter (max 1000)
- Loading state on submit, success panel, and "send another" reset
- Toast notifications for validation and success
- Fully responsive and keyboard accessible
- No backend required — simulates submission with a short delay

## Run

Open `index.html` in a modern browser.
